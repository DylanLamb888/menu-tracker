## Codebase Patterns

### Database
- Drizzle ORM with Neon Postgres, schema in `lib/db/schema.ts`
- Use `db.select().from()` with `.where()` for queries
- Batch fetches with `inArray()` to avoid N+1

### Auth
- Password-only auth via `lib/auth.ts`
- `getCurrentUser()` returns user or null (cached per request via `React.cache()`)
- JWT in HTTP-only cookie, 30-day expiry
- Middleware redirects unauthenticated users to /login

### Components
- shadcn/ui (new-york style) in `components/ui/`
- `cn()` from `@/lib/utils` for className merging
- App shell wrapper for consistent layout
- Status colors: Draft=#9CA3AF, In Review=#F59E0B, Approved=#10B981, Live=#E07A5F

### API Routes
- Next.js App Router in `app/api/`
- Always check auth via `getCurrentUser()`
- Wrap in try-catch, return `NextResponse.json()` with status codes

### Performance
- Hoist `Intl.DateTimeFormat` outside components
- `useMemo` for Maps in lookups
- `next/dynamic` with `ssr: false` for react-pdf
- `optimizePackageImports` in next.config.ts for lucide-react
