# Menu Tracker Progress Log

## Codebase Patterns

### Database
- Drizzle ORM with Neon Postgres (switched from @vercel/postgres)
- Schema in `lib/db/schema.ts`, connection in `lib/db/index.ts`
- Use `db.select().from()` with `.where()` for queries
- Batch fetches to avoid N+1 (see `app/menus/[id]/page.tsx` for pattern)

### Auth
- Password-only auth via `lib/auth.ts`
- `getCurrentUser()` returns user or null
- JWT in HTTP-only cookie, 30-day expiry
- Middleware redirects unauthenticated users to /login

### Components
- shadcn/ui (new-york style) in `components/ui/`
- Custom components in `components/`
- App shell wrapper for consistent layout
- Status colors: Draft=#9CA3AF, In Review=#F59E0B, Approved=#10B981, Live=#E07A5F

### API Routes
- Next.js App Router API routes in `app/api/`
- Always check auth via `getCurrentUser()`
- Return `NextResponse.json()` with appropriate status codes

### File Storage
- Vercel Blob for PDFs via `lib/blob.ts`
- `uploadPdf()` helper returns URL and filename

### Permissions
- Role-based permissions in `lib/permissions.ts`
- `canChangeStatus()` and `getAvailableTransitions()` for status workflow

### Performance Patterns
- Hoist `Intl.DateTimeFormat` outside components (recreating is expensive)
- Use `useMemo` for Maps used in lookups within components
- Hoist static JSX elements outside components to avoid recreation
- Use `next/dynamic` with `ssr: false` for large client-only libs (react-pdf)
- `optimizePackageImports` in next.config.ts for icon libraries
