## Codebase Patterns

- Use `cn()` from `@/lib/utils` for className merging
- shadcn/ui components go in `components/ui/`
- Path alias `@/*` maps to project root
- Color palette: cream (#FAF7F2), coral (#E07A5F), deep brown (#3D2E2E)
- Status colors: Draft (#9CA3AF), In Review (#F59E0B), Approved (#10B981), Live (#E07A5F)
- Database: Drizzle ORM with Vercel Postgres, schema in `lib/db/schema.ts`
- Database connection: `db` export from `@/lib/db`
- Migrations: `bun run db:generate` to generate, `bun run db:push` to push to DB
- DB scripts use `dotenv-cli` to load `.env.local` automatically
- Need `POSTGRES_URL` alias in `.env.local` pointing to `menutrackerdb_POSTGRES_URL`
